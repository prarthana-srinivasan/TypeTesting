# ⌨️ TypeTesting – Typing Speed Test
 
TypeRush is a sleek, feature-rich typing speed test application designed to help users improve their typing speed and accuracy. The application provides real-time WPM tracking, accuracy measurement, difficulty levels, grading system, dark/light mode, and local history tracking.

## Live Demo
 
🔗 https://prarthana-srinivasan.github.io/TypeTesting/
 
---
 
## Features
 
### Typing Test
- Real-time WPM (Words Per Minute) calculation
- Live accuracy tracking
- Letter-by-letter visual feedback (green = correct, red = wrong)
- Animated blinking cursor
- Smooth word scrolling
### Difficulty Levels
- **Easy** – Common everyday words, 60 seconds
- **Medium** – Intermediate vocabulary, 60 seconds
- **Hard** – Complex technical words, 90 seconds
### Grading System
- Grade S – 80+ WPM (Legendary 🏆)
- Grade A – 60+ WPM (Excellent 🌟)
- Grade B – 40+ WPM (Good 💪)
- Grade C – 25+ WPM (Average 📝)
- Grade D – Below 25 WPM (Keep Practicing 🎯)
### Stats Tracking
- Live WPM speed
- Accuracy percentage
- Correct word count
- Error count
- Animated circular countdown timer (blue → yellow → red)
### Dark / Light Mode
- Toggle between dark and light themes
- Theme saved to localStorage
- Smooth transition animation
### History
- Saves last 10 test results in localStorage
- Shows WPM, accuracy, difficulty, and time
- Clear history option
### Keyboard Shortcut
- Press **Tab** to instantly restart the test
### User Experience
- Responsive design
- Mobile-friendly layout
- Smooth animations and transitions
- Input shake animation on wrong word

## How to Use
 
1. Select difficulty — **Easy / Medium / Hard**
2. Click the input box or start typing
3. Type the words shown on screen
4. Press **Space** to submit each word
5. View your results when time runs out
6. Press **Tab** anytime to restart
7. Check your history at the bottom
